# bhugol-medium: BHUGOL medium-length country-facts videos (6–10 min, 16:9)

The `bhugol-medium` skill is the how-to. It runs the shared engine in `bhugol-gta/engine/` (born on the GTA video, generalised on Romania and the Philippines).

- Worked examples: `bhugol-gta/example-philippines-facts/` (latest; music v3, thumbnail study, numerals alignment) and `bhugol-gta/example-romania-facts/` (EN + HI).
- Music: branch `music` (`library.json`, `ytal/`, `kevin-macleod/`).
- Thumbnail research: Project doc `claude/thumbnail_research_longform.md`; tools in `bhugol-gta/example-philippines-facts/thumb/`.
- Changes to the skill are logged in `LEDGER.md` here.

# Example: Delhi smog (3D, 13 Nov 2026), trend-rider, code-drawn, India official boundary

- **India's official boundary on every map:** Natural Earth `ne_10m_admin_0_countries_ind` (India point-of-view layer; Gilgit, Muzaffarabad and Aksai Chin inside), fetched from raw.githubusercontent.com. The globe flag-fill, the rising border wall and the cover outline all use it (`art/geo.json`).
- **Real satellite haze:** NASA GIBS WMS `VIIRS_NOAA20_CorrectedReflectance_TrueColor` with `&TIME=<date>` (in the smog-map fetch job). The Terra/Aqua/SNPP swaths have black gaps; NOAA-20 on 12 Nov was gap-free. It is blended onto the terrain by a `haze` uniform and used as DOM plates (`plate()`).
- **Scenes:** MP (map3 + haze + smog particles + state mask: idx 1-5 lit west to east, Delhi idx 8 = cyan), XS (clay N-S cross-section: Himalaya, plain, Aravalli/Vindhya; summer smoke rising to 1 km vs a November warm lid at ~0.3 km; cold-air ribbon off Tibet; pot lid; wind streaks), GA/GB (NASA plates), AQI gauge, 100-city grid, Himalaya character drawn in SVG.
- **Narration:** Higgsfield Holden (EN seed_audio 7.4 credits; HI ElevenLabs 3.45 credits), aligned with mm3 `words_fit.py` + `align.py` + `voices.py` (him -3 st). Mix: `example-baikal-3d/tools/mixbk.py` + `motion/sfxlayer.py` (the kit could not be loaded).
- **Renders:** hyperframes needs `HYPERFRAMES_BROWSER_PATH=/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell` (the 1194 path no longer exists). Run renders via a background tool call, not `nohup &` (the render is cancelled when the parent shell exits). EN 71.5 s took ~45 min; HI 75.6 s ~45 min.
- **GitHub mailbox gotcha:** only one pending run per workflow group, so another chat's push can silently drop your queued align/fetch job. If outputs don't appear after the run before yours finished, bump `"try"` and push again.
- QA: retention PASS (EN 95% moving, 2.1 s cadence; HI 96%, 2.1 s), sound-on-beat 50/50 both.

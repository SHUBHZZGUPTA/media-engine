# Money Mirage standalone Shorts (money-mirage-shorts skill)

One folder per Short: `sNNN-<slug>/` (English) with `hi/` (Hindi, same shots re-timed). Build with `mm3/tools/build.py --port`,
render with `render_all.sh`, master with `mm3/tools/finish_short.sh <thumb_v.jpg> <out.mp4>`.
